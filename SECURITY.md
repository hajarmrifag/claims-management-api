# Security policy

## Supported version

This portfolio project supports the current `main` branch. It is a demonstration
application and must not be used to process real insurance, identity, payment, or
medical data.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature for this repository instead. Include:

- the affected endpoint or component
- the conditions required to reproduce the issue
- a minimal proof of concept that does not access third-party data
- the expected impact and any suggested remediation

Do not test the public demonstration in a way that degrades availability,
accesses another user's data, or uploads active malware. Reproduce findings in a
local environment whenever possible.

## Response goals

I will acknowledge a complete report within five business days, assess its
severity and scope, and document the remediation and verification steps. No
bounty or payment is offered for this educational portfolio project.
